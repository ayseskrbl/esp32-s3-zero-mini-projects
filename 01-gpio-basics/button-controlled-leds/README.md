# Button-Controlled LEDs

## Objective
Control two LEDs independently using two physical push buttons with the ESP32-S3.

## Hardware
- ESP32-S3-Zero
- 2 LEDs (red and green)
- 2 push buttons
- 2 × 330Ω resistors
- Breadboard and jumper wires

## Concepts Practiced
- GPIO input and output configuration
- Internal pull-up resistors
- Digital input reading
- Independent button control
- Controlling multiple LEDs

## Result
Each button independently controls its corresponding LED.

- Red button → Red LED
- Green button → Green LED

## Next Step
Implement software debounce to improve button input reliability.
