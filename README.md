# ESP32 Learning Lab

A hands-on learning repository documenting my journey into embedded systems development using the ESP32-S3 and ESP-IDF.

This repository contains small experiments, circuit simulations, code examples, and notes created while learning embedded programming and hardware fundamentals.

## Goals

- Learn embedded C programming.
- Understand GPIO, digital input/output, and basic electronics.
- Work with buttons, rotary encoders, and displays.
- Explore SPI communication and peripheral integration.
- Gain practical experience with ESP-IDF and FreeRTOS.
- Experiment with Bluetooth Low Energy (BLE).

## Hardware & Tools

- **Microcontroller:** ESP32-S3
- **Framework:** ESP-IDF
- **Language:** C
- **Simulator:** Wokwi
- **IDE:** Visual Studio Code
- **Hardware:** ESP32-S3-Zero, breadboard, and electronic components
